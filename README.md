# だるまさんを起こして！ / WAKE SEVEN

7枚のパネルを回して、だるまさんを起こすブラウザパズルです。公開版: <https://wake-seven.github.io/>

水色の棒をつかんで回します。全員が起きたらクリアです。進行状況はブラウザの Local Storage に保存されます。

## ファイル

- `index.html` — 公開中のゲーム本体で、開発時もこの1枚が正本です。ビルド工程はありません。
- `all-patterns.html`、`index_3D.html` — ゲーム中の報酬から開く付属ページです。
- `assets/social/` — 公開ページとSNS用の画像などです。
- `AGENTS.md` — 次の開発者・AI向けの短い引き継ぎです。

開発時は、まず `AGENTS.md` を読んでください。
