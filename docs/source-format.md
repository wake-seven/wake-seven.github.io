# ソース可読性の整形方針

JavaScript と CSS の制御コードは、処理の流れと差分が追いやすい改行・インデントを優先する。
公開版の単体 `index.html` は生成物なので直接編集しない。

## 対象

- `src/**/*.js`
- `src/**/*.mjs`
- `src/index.template.html` の CSS

## 対象外

- SVG の `d` 属性と SVG テンプレート文字列
- favicon・data URI
- 問題データ、多言語データ、生成済み JSON

対象外を無理に整形すると、アートやデータの差分が増え、意図しない変更を見落としやすくなるためである。

## 目安

- 1 行 1 文を基本とする
- 長い引数、オブジェクト、条件分岐は複数行にする
- CSS は既存方針に合わせて 1 ブロック 1 行を維持する
- CSS はJavaScriptの制御コード行長監査から除外する
- JavaScript制御コードの 160 文字超は `npm run check:source-format` で警告する

現時点では既存コードを一括変換せず、監査レポートで対象を可視化する。新規変更では警告を増やさない。大きな整形は機能変更と混ぜず、ファイル単位で検証する。
